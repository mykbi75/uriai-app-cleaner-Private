우리아이 앱청소 개인정보처리방침

시행일: 2026년 10월 28일 · 개발자: BI MEDIA (빛마루)

요약: 우리아이 앱청소는 어떤 개인정보도 수집하거나, 저장하거나, 외부로 전송하지 않습니다. 인터넷 권한도 사용하지 않습니다.

1. 앱이 사용하는 정보

앱은 정리할 앱을 보여주기 위해 이 휴대폰에 설치된 앱의 이름·아이콘·설치 날짜·설치 경로(스토어 등)·용량을 휴대폰 안에서만 읽습니다. 이 정보는 화면에 목록을 보여주는 데만 쓰이며, 어디로도 전송되지 않습니다.

2. 휴대폰에 저장하는 정보

사용자가 직접 지정한 "내 앱(보호)" 목록과 "폰 빌려주기 전 기억하기" 시점의 앱 목록만 휴대폰 안에 저장됩니다. 앱을 삭제하면 함께 지워집니다.

3. 앱 삭제 기능

앱은 안드로이드 기본 삭제 화면을 띄워 줄 뿐이며, 실제 삭제는 사용자가 앱마다 "확인"을 눌러야 진행됩니다. 사용자 몰래 앱을 지우지 않습니다.

4. 제3자 제공 · 광고 · 분석

제3자에게 정보를 제공하지 않으며, 광고나 분석 도구(SDK)를 포함하지 않습니다.

5. 아동의 개인정보

이 앱은 보호자(부모)가 사용하도록 만들어졌으며, 아동을 포함한 누구의 개인정보도 수집하지 않습니다.
