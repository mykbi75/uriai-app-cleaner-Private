# 플레이스토어 등록 문구 (복사해서 붙여넣기)

## 앱 이름 (30자 이내)
우리아이 앱청소 - 아이가 깐 앱 한번에 삭제

## 간단한 설명 (80자 이내)
아이에게 폰 빌려준 뒤 몰래 깔린 게임·광고 앱, 체크하고 한 번에 정리하세요!

## 자세한 설명 (4000자 이내)
아이에게 잠깐 폰을 빌려줬더니… 모르는 게임, 광고 보다 깔린 앱이 잔뜩?
하나씩 찾아서 지우기 번거로우셨죠. 우리아이 앱청소가 한 번에 정리해 드려요.

■ 이렇게 써요
① 폰을 빌려주기 전, [폰 빌려주기 전에 눌러두세요] 버튼을 한 번 누르세요.
② 폰을 돌려받고 앱을 열면, 그 사이 새로 깔린 앱만 모아서 보여드려요.
③ 지울 앱을 체크하고 [한번에 지우기]! 확인 창에서 '확인'만 차례로 누르면 끝.

■ 주요 기능
• 새로 깔린 앱 찾기 — '기억한 시점 이후' 또는 오늘·3일·7일·30일
• 게임만 모아 보기 — 휴대폰에 깔린 게임을 한눈에
• 출처 불명 앱 찾기 — 광고·링크·파일로 깔린 앱은 빨간 표시로 알려드려요
• 여러 개 체크해서 한 번에 삭제 — 하나씩 찾아다닐 필요 없어요
• 내 앱 보호 — 은행·메신저처럼 중요한 앱은 꾹 눌러 '내 앱'으로 지정하면 실수로 지워지지 않아요
• 정리 결과 — 몇 개를 지웠고 공간이 얼마나 늘었는지 알려드려요

■ 안심하세요
• 개인정보를 전혀 수집하지 않아요. 인터넷 권한도 쓰지 않아요.
• 광고가 없어요.
• 몰래 지우지 않아요. 안드로이드 보안 규칙에 따라 앱마다 직접 '확인'을 눌러야 삭제돼요.
• 휴대폰 기본 앱은 목록에 나오지 않아요.
